# Documentation fournie (DOCUMENT D'EXEMPLE FICTIF)

## Documentation technique

Une documentation technique complète est livrée avec la solution :
architecture, schéma de données, description des interfaces et procédures d'installation.

## Guide administrateur

Un guide administrateur décrit la gestion des utilisateurs, la configuration,
la supervision et les procédures de sauvegarde et de restauration.

## Formation

Une session de formation de deux jours est proposée aux équipes d'administration.
